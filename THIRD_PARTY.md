# Third-party components

Application code is MIT licensed. Installers retrieve packages through pip. Review the installed packages' own license files for redistribution terms. Major dependencies include OpenCV (Apache-2.0 for recent releases), NumPy/SciPy (BSD-style), PySide6 (LGPLv3/GPL/commercial options), PyQtGraph (MIT), Matplotlib (its project license), PyYAML (MIT) and psutil (BSD-style).

The OpenCV Haar cascade comes from the OpenCV package and retains its upstream notices. Optional MediaPipe models are downloaded from Google's public model distribution and retain model-specific terms. Optional YuNet comes from OpenCV Zoo and retains its model/license notices. Model weights are not covered by this repository's MIT license and are not bundled in the ZIP.

The synthetic demo uses generated ellipses and geometric features; it contains no real person's biometric data. Dashboard screenshots are generated from that demo. No external face photographs are redistributed.
